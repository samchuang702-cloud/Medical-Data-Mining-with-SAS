# 醫療資料探勘 — 肺炎病人死亡風險預測

## 專案簡介

本專案為「醫療資料探勘」課程期末作品，先使用 SAS Enterprise Guide（SAS EG）完成門診、住院與死亡資料的整併及特徵工程，再使用 SAS Enterprise Miner（SAS EM）建立機器學習模型，預測肺炎病人的死亡風險。

## 想解決的問題

- 如何從門診與住院資料建立肺炎病人研究族群？
- 年齡、地區、就醫型態與共病是否能協助辨識死亡風險？
- 邏輯斯迴歸與決策樹何者具有較佳的驗證表現？
- 如何將 SAS EG 的資料處理流程銜接至 SAS EM 建模流程？

## 技術方法

1. 整併四份門診資料，並串接住院資料。
2. 以 ICD-9-CM 主診斷碼 `486` 篩選肺炎病人。
3. 建立門診／住院來源、年齡、年齡層、65 歲以上、80 歲以上及地區特徵。
4. 依診斷碼建立 COPD、糖尿病、心衰竭與慢性腎病共病指標。
5. 去除重複病人，建立供 SAS EM 使用的病人層級建模資料。
6. 以 70% 訓練集與 30% 驗證集建立邏輯斯迴歸及決策樹。
7. 比較 ROC、Gini、KS、平均平方誤差、誤分類率與平均利潤。

## SAS EM 建模流程

```text
資料來源 → 資料分割（70% / 30%）
                         ├─ 邏輯斯迴歸
                         ├─ 決策樹
                         └─ 模型比較 → 最終模型
```

## 模型結果

| 驗證指標 | 決策樹 | 邏輯斯迴歸 |
|---|---:|---:|
| ROC Index | 0.810 | **0.850** |
| Gini | 0.620 | **0.700** |
| KS | 0.586 | **0.590** |
| 平均平方誤差 | 0.082 | **0.080** |
| 誤分類率 | 0.369 | **0.312** |
| 平均利潤 | **0.793** | 0.784 |

SAS EM 依「驗證集平均利潤」選擇決策樹；若以 ROC、Gini、平均平方誤差及誤分類率衡量，邏輯斯迴歸表現較佳。這顯示最終模型選擇會受到業務目標與評估指標影響。

## 使用技術

SAS Enterprise Guide、SAS Enterprise Miner、SAS DATA Step、PROC SQL、PROC SORT、邏輯斯迴歸、決策樹、模型驗證與比較。

## 專案亮點

- 完成從醫療資料清理、研究族群建立到預測建模的端到端流程。
- 將門診、住院、人口特徵與共病資訊整併為病人層級資料。
- 同時比較模型的判別力、預測誤差、分類結果與利潤指標。
- 展現 SAS EG 資料工程、SAS EM 機器學習與醫療資料解讀能力。

## 執行方式

1. 使用 SAS Enterprise Guide 開啟 `pneumonia_mortality_preprocessing.sas`。
2. 修改程式最上方的專案資料路徑。
3. 準備具合法使用權限的門診、住院及死亡資料後執行程式。
4. 將產生的 `MODEL_READY` 資料表註冊至 SAS Enterprise Miner。
5. 依上述流程進行資料分割、模型訓練與比較。

## 資料隱私

本 repository **不包含任何原始醫療資料、死亡名冊、病人識別碼、SAS 資料表或個人層級輸出**。公開程式僅用於展示資料處理與建模方法；使用者必須自行取得合法資料授權並遵守相關資料治理規範。
